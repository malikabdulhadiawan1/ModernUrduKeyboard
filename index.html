Phonetic key — what each letter types

This is a simplified Roman-Urdu scheme, not an official standard — built for speed, not linguistic completeness. Capital letters reach the "heavier" Arabic-origin sounds (e.g. t → ت but T → ٹ, H → ح). Letters without a common English sound (ص ض ط ظ ذ ث ع ھ ء ں) are click-only — find them on the keyboard above. Number keys 1–9 are reserved for diacritics while phonetic typing is on, so plain digits won't type directly in that mode — switch the toggle off if you need to type numbers.
